# Меню платформы

В левом меню, в разделе **«Работа с кабинетом»**, над «Взаимодействиями»:

1. Действия по артикулам.
2. Точки входа (WB).
3. Фотоворонка (WB).
4. Сравнение карточек.

Показаны только вкладки выбранного маркетплейса. Личные настройки скрытия
вкладок и закрепления в верхней панели сохраняются. Чтобы вернуть скрытую
вкладку, откройте «Вкладки → Настроить»; эти инструменты собраны там в группу
«Работа с кабинетом».

Пункт «Пригласить друга» временно скрыт. Доступ сотрудников выдаётся как
прежде через «Пользователи и права».

В **«О сервисе → Команда»** размещена ссылка на канал автора платформы:
[Максим Попов. Система и масштабирование на МП](https://t.me/maxim_popov_wb).
Подписывайтесь на канал. Ссылка автора не заменяет контакты поддержки
вашей установки и не меняет её реквизиты.

## Обновление существующей установки

Сначала создайте проверяемую резервную копию базы и конфигурации, затем
обновляйте код по [инструкции эксплуатации](OPERATIONS.md). Повторный
bootstrap и замена базы не нужны. Эти изменения меню не меняют ключи,
пользователей, магазины, расчёты и сохранённые настройки. После штатной
сборки и перезапуска сайта обновите страницу браузера.
