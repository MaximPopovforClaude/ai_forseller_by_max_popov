Публичная версия сохраняет оригинальные логотипы **AI-100metric by Max Popov** во всех существующих местах интерфейса. При установке и обновлении сохраняйте их и подпись автора; подробности — [айдентика платформы](docs/BRANDING.md).

Исходники платформы аналитики: Python/FastAPI, PostgreSQL, React/TypeScript. Данные поступают из ваших API маркетплейсов. Установка начинается с пустой базы; пользователь, магазины, ключи и история создаются на вашем сервере.

**Автор проекта — Максим Попов. Подписывайтесь на [Telegram-канал «Максим Попов. Система и масштабирование на МП»](https://t.me/maxim_popov_wb).** В канале — опыт работы на Wildberries и Ozon, управление командой и развитие бизнеса на маркетплейсах.

Сначала прочитайте [статус лицензии](LICENSE-STATUS.md). Это отдельный репозиторий с новой историей, без данных исходной установки.

## Начать

Репозиторий: [ai_forseller_by_max_popov](https://github.com/MaximPopovforClaude/ai_forseller_by_max_popov).

Для полной схемы с витринными ценами WB нужны **два сервера**: основной для сайта, базы и ИИ и отдельный VPS **в России** для сбора цен. Аренда второго сервера и его настройка — отдельный этап. Код сборщика, установщик и адаптер включены: настройте собственное соединение по [инструкции российского сервера](docs/RUSSIAN-SERVER.md). Сайт и отчёты API можно запустить раньше, но это не означает готовность витринных цен.

1. [Установить платформу](docs/INSTALL.md) на отдельный Linux-сервер.
2. Или открыть репозиторий в Claude Code / Codex и передать [общее задание на оба сервера](docs/AI-GUIDE.md). Для уже работающего сайта есть [полное задание на российский VPS](docs/AI-RUSSIAN-SERVER.md).
3. Проверить [приёмку](docs/ACCEPTANCE.md), затем подключать реальные магазины.
4. Подключить [своего Стометрика на сайте и в Telegram](docs/STOMETRIC.md), или передать [задание помощнику](docs/AI-STOMETRIC.md).
5. Настроить [резервное копирование и обновления](docs/OPERATIONS.md).

В комплекте **плагин Chrome 0.2.9**: исправлены смешивание сессий WB между вкладками
и использование сессии после отказа 401. Скачивайте ZIP со своей установки: он уже настроен на её домен. Для папки из Git
есть отдельный шаг по [инструкции плагина](extension/README.md). После обновления файлов
перезагрузите расширение в Chrome и вкладку кабинета WB.

| Возможность | Что нужно в своей установке |
|---|---|
| Таблицы, дашборды, PnL, остатки, реклама, себестоимость, планирование | Ключи своих магазинов WB/Ozon, завершённый сбор, себестоимость и налоговые настройки |
| Пользователи, роли, календарь, задачи команды | Первый администратор, затем участники и права на магазины |
| Точки входа WB | Собственный плагин Chrome или ручная загрузка отчётов продавца |
| Стометрик на сайте и в Telegram | Гномик, чат и бот включены; личный VIP владельца либо API кабинета, свой Telegram-бот и привязка пользователей. [Настройка](docs/STOMETRIC.md) |
| ИИ-сводки, SEO, помощь с карточками | VIP владельца либо собственный API-ключ нейросети |
| Ежедневные ИИ-задачи WB/Ozon | VIP или API, полные источники, явное включение магазина и таймера; расходуются лимиты или средства API |
| GPT Image | [Личный ChatGPT владельца через VIP](docs/PERSONAL-AI.md), после проверки доступа; либо отдельный ключ OpenAI API |
| Higgsfield, Google, Wildbox, Telegram | Свои учётные записи и настройки каждого сервиса |
| Витринные цены WB и «Полки» через внешний браузер | Код в `infra/egress/` и SSH-адаптер включены; нужны свой российский VPS, установка и проверка. [Порядок](docs/RUSSIAN-SERVER.md) |
| Личная подписка разработчика, бот разработки и его память | Чужие подписка, бот и память не распространяются. Свой VIP настраивается по [инструкции](docs/PERSONAL-AI.md) |

Код расчётов перенесён; полнота результата зависит от источников, периода и настроек магазина. Первичная загрузка большого магазина может занять несколько циклов. Пустой отчёт до загрузки данных не считается доказательством отсутствия заказов.

Новая установка не имеет доступа к данным, подпискам, серверам или аккаунтам создателя проекта. Не переносите чужую базу, `.env`, историю чатов, cookie браузера или каталог авторизации Claude/Codex.

Проверки этой сборки и их ограничения фиксируются в [VALIDATION.md](docs/VALIDATION.md). Новая установка на вашем сервере требует своей приёмки.

## Личная подписка владельца

В админке есть VIP для своих магазинов: аналитика, Стометрик на сайте и в Telegram, GPT Image. [Подключение, команды и задание Claude/Codex](docs/PERSONAL-AI.md). На новом сервере нужны собственный вход ChatGPT, выбор магазинов и проверка. Клиенты работают по API.
