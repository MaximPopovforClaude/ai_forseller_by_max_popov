# Приёмка своей установки

- Оригинальные логотипы AI-100metric by Max Popov сохранены на входе и в меню, обе темы отображаются правильно, подпись автора читается. Favicon и логотип расширения загружаются локально. См. [BRANDING.md](BRANDING.md).

- Миграции проходят на пустом PostgreSQL 16. До bootstrap нет пользователей, магазинов, рабочих пространств и новостей чужой установки.
- Bootstrap создаёт одного администратора и его рабочее пространство. Повтор на непустой базе отвергается.
- Вход через HTTPS работает; выход закрывает сессию. В адресах приглашений, расширения и OAuth указан ваш домен.
- Участник с доступом к одному магазину не получает данные другого. Администратор одного магазина не меняет общий платёжный API-ключ.
- Сбор собственного тестового магазина проходит и отражается в «Статусе обновления». На дашборде сравните число/сумму заказов с тем же источником за тот же полный день. Разные источники не обязаны совпадать.
- Главная не остаётся поверх других вкладок; вкладки отображают текущий магазин и период.
- Плагин загружает дневные точки входа в нужный магазин; даты и строки видны в платформе. Неполные источники не запускают полноценный ИИ-разбор.
- Если согласованы витринные цены WB: отдельный российский сервер и адаптер подключены по [инструкции](RUSSIAN-SERVER.md); несколько карточек сверены при одинаковых условиях цены, результат и время видны на основном сайте. Сбой связи не превращается в нулевую цену, параллельные браузеры цен/полок не запускаются. Без этой проверки витринный сбор остаётся незавершённым.
- Один согласованный API-запрос проходит, использует ключ вашего аккаунта, сохраняет результат и не повторяется автоматически при неопределённом исходе.
- Стометрик отвечает на один согласованный вопрос на сайте и в собственном Telegram-боте; история сохраняется. Привязка одноразовая, повторная/истёкшая ссылка не работает; чужой пользователь не получает чат или магазин, отзыв доступа действует и до исполнения вопроса.
- Один bots.service работает без старого бота уведомлений. Второй локальный процесс блокируется. Три фоновые настройки по умолчанию выключены; уведомления включаются отдельно от платных утренних и рекламных ИИ-разборов. После согласования проверено одно уведомление и напоминание календаря. Полный порядок — [STOMETRIC.md](STOMETRIC.md).
- Таймеры работают после выхода из SSH. Резервная копия восстанавливается в отдельную базу; ключ шифрования сохранён отдельно и доступен владельцу.

Отметьте фактические результаты и ограничения в локальном журнале. Проверка компиляции или HTTP 200 не заменяет эти сценарии.

- При выборе VIP пройдены setup/login/check, выбраны только свои магазины, проверены один ответ сайта и Telegram и одно изображение GPT Image. Чужой магазин/участник не получают подписку; отзыв доступа действует до отправки. Платный API не используется при сбое VIP. Без живой проверки отмечайте подписочную интеграцию непроверенной. См. [PERSONAL-AI.md](PERSONAL-AI.md).
