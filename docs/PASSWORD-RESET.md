# Восстановление пароля

Администратор сервиса открывает **Админка → Пользователи → Сбросить пароль**.
Он может создать ссылку, скопировать её и лично передать получателю либо
отправить её в ранее привязанный Telegram. Создание ссылки само по себе
не меняет пароль. Ссылку не публикуйте в общем чате: она даёт право сменить пароль.

В **Пользователи и права** администратор всего кабинета может отправить
восстановление сотруднику в Telegram. Ручная выдача ссылки доступна только
суперадмину сервиса. Ограниченный доступ к отдельным магазинам и режим
поддержки этого права не дают. Сброс меняет пароль всего пользователя,
а не одного магазина; его прежние права в кабинетах сохраняются.

На странице входа есть «Забыли пароль?». Через бота регистрация определяется
по ранее привязанному Telegram; чужой адрес получателя указать нельзя.
Если своего бота регистрации нет, используйте личную передачу ссылки администратором.

Ссылка действует 30 минут и используется один раз. Новый выпуск отменяет
предыдущую ссылку. После успешной смены закрываются прежние веб-сессии и
ссылки входа, отзываются MCP/плагин-коды этого пользователя; их нужно получить
заново. Сохранённые магазины и API-ключи маркетплейсов не изменяются.

**Домен:** задайте свой HTTPS-адрес в `SITE_URL` по [INSTALL.md](INSTALL.md).
Ссылка и проверка Origin используют этот адрес. За обратным прокси браузер
должен открывать тот же домен; при смене домена обновите конфигурацию и
перезапустите приложение. Не отключайте проверку Origin ради устранения ошибки.

Реальные пароли/ссылки не нужны разработчику. В базе хранится хеш одноразового
токена; секрет ссылки находится после `#`, затем убирается из адресной строки.
При ошибке отправки Telegram ссылка отзывается без автоматического повтора.
