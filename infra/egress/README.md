# Российский сборщик WB

В этот каталог входят исходники второго сервера: цены (`wbshow.py`), полки
(`wbshelf.py`), общий браузер, протокол, установщик и запуск с блокировкой.
На основном сервере используются `stometric/egress.py`,
`scripts/configure_egress.py` и `scripts/egress_check.py`.

Полный порядок установки, SSH, проверок и обновления:
[docs/RUSSIAN-SERVER.md](../../docs/RUSSIAN-SERVER.md).

Работа только с публичной гостевой витриной WB. Логины, сессии продавца,
API-ключи магазинов, база и подписка нейросети не нужны. Адрес назначения
настраивается; по умолчанию используется регион Москвы (`-1257786`).
Цены возвращаются в рублях, исходный объём — в десятых долях литра;
преобразование объёма для основной платформы выполняет адаптер.

Браузер запускается обычным пользователем с `chromium_sandbox=True`,
без изменения признаков автоматизации. При отказе источника сбор останавливается;
обход CAPTCHA или повторное открытие ради обхода 403/429/498 не выполняется.
Регион/IP и текущая структура WB требуют приёмки на каждом новом сервере.

Версия Playwright закреплена в `requirements.txt`. Как установка браузера
зависит от версии пакета: [официальная документация](https://playwright.dev/python/docs/browsers).
Песочница включается явно: [параметр Chromium sandbox](https://playwright.dev/python/docs/api/class-browsertype#browser-type-launch-option-chromium-sandbox).
