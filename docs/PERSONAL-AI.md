# VIP: свой ChatGPT как нейросеть платформы

VIP подключает личную подписку владельца к аналитике, сводкам, задачам, Стометрику на сайте и в Telegram. В «Визуале» доступен GPT Image через ту же подписку, если эту возможность и оставшиеся лимиты подтверждает Codex. API-ключ для этого маршрута не требуется.

Автор платформы — Максим Попов. **Подписывайтесь на [Telegram-канал автора](https://t.me/maxim_popov_wb)**: продажи на маркетплейсах, команда и развитие платформы.

## Границы доступа

Это личная установка собственника и его магазины. Подпиской пользуется только настроивший её активный суперадминистратор с полной ролью владельца выбранного кабинета. Магазины выбираются явно. Добавление чужого клиента, выдача роли или переключение тарифа не дают права пользоваться подпиской. Сторонние клиенты работают через отдельные API-ключи своих кабинетов; запрос владельца в клиентском магазине тоже идёт по API. Автоматического перехода между маршрутами нет.

Общий коммерческий тариф по подписке владельца не предоставляется. VIP не продаётся в списке платных тарифов. Источники и лимиты пользователя проверяются на постановке и перед выполнением; отзыв доступа останавливает ещё не отправленную работу. Уже отправленный запрос мог израсходовать лимит.

## 1. Обновить установку

Сделайте закрытую резервную копию базы и файлов, остановите свои сервисы по docs/OPERATIONS.md, получите обновление и примените миграции. Миграция `900_selfhost_personal_ai.sql` добавляет VIP в админку. Она не назначает тариф пользователям автоматически и не включает фоновые задачи. Соберите фронтенд и запустите свои сервисы. Полный порядок — [INSTALL.md](INSTALL.md).

## 2. Установить Codex и войти

На **основном** сервере, от того же непривилегированного Linux-пользователя, который запускает сайт и бота, установите официальный [Codex CLI](https://learn.chatgpt.com/docs/quickstart). Требуется версия с app-server, named permission profiles, trusted hooks, model capabilities и структурированными лимитами. Протокол меняется; несовместимая версия должна отказать при проверке, а не отключить защиту.

Из корня проекта выполните:

```bash
.venv/bin/python scripts/personal_ai.py setup
.venv/bin/python scripts/personal_ai.py login
.venv/bin/python scripts/personal_ai.py check
```

`setup` создаёт отдельный профиль `data/personal-ai/codex` и разрешает только защитный hook из `stometric/owner_policy.py`. Он не меняет профиль разработчика. При несовпадении существующей конфигурации остановится; сначала выясните причину, не удаляйте настройки вслепую. Если файлы hook обновились, изучите изменения и повторите setup.

`login` запускает штатный `codex login --device-auth`. Откройте показанную ссылку на своём устройстве и войдите в **свой ChatGPT**. Если требуется, разрешите device code authentication в настройках безопасности ChatGPT. Код вводится только на странице OpenAI. Пароль, токены и содержимое профиля не передавайте установщику, в чат, на сайт платформы или в публичный Git. [Официальная справка входа](https://learn.chatgpt.com/docs/auth).

`check` проверяет тип входа, доступную модель, защиту, отсутствие сторонних MCP-инструментов, лимиты и GPT Image. Диагностика не запускает генерацию. `text_ready: true` и `image_ready: true` — раздельные результаты; отказ одного не выдаётся за успех другого. Не входите через API-ключ в профиль VIP.

## 3. Включить VIP на сайте

Откройте **«Админка сервиса → Кабинеты и тарифы»**, блок **«VIP · личная подписка ChatGPT владельца»** под таблицей.

1. Выберите свой кабинет и отметьте принадлежащие вам магазины.
2. Нажмите «Проверить подключение». Посмотрите отдельные статусы текста и GPT Image.
3. Нажмите «Включить VIP / сохранить выбор». Сервер повторно проверит подключение и назначит этому кабинету VIP.
4. Создайте новый чат Стометрика: старые чаты прежнего маршрута после включения VIP или смены списка магазинов не продолжаются, чтобы их данные не попадали в подписку. Проверьте один короткий вопрос Стометрику на сайте. Сравните его цифры с таблицей.
5. Подключите собственного Telegram-бота и привяжите свой аккаунт по [STOMETRIC.md](STOMETRIC.md). Задайте один вопрос из Telegram: история сохраняется в той же платформе, маршрут подписки общий с сайтом.
6. В «Визуале» выберите «GPT Image · личная подписка ChatGPT», загрузите исходные фото своего товара и явно запустите одну генерацию. Проверьте сохранённое изображение.

Пункт VIP в выпадающем списке существует, но одной смены тарифа недостаточно: нужны вход, выбранные магазины и успешная проверка в блоке ниже. Вход в Codex, который разрабатывает сайт, сам по себе не подключает ИИ платформы.

## Лимиты и фоновые задачи

Используется штатный [Codex app-server](https://learn.chatgpt.com/docs/app-server) и встроенная [генерация GPT Image](https://learn.chatgpt.com/docs/image-generation). Модель берётся из доступного списка аккаунта; её название и доступность изображений не обещаются независимо от подписки. Интерфейсы app-server экспериментальные: после обновления Codex повторите диагностику и приёмку.

Текст и изображения расходуют лимиты владельца. Изображение обычно расходует больше лимита, чем текст. Безлимитность не обещается. Если лимит исчерпан, данные о нём неполные либо в аккаунте доступны дополнительные кредиты, обработчик не отправляет запрос. Это консервативная проверка перед отправкой, а не серверный предел оплаты провайдера: изменение квоты другим сеансом в момент выполнения исключить нельзя. Отключите автоматическое пополнение кредитов и не используйте этот профиль для других сеансов.

Ошибки и неопределённые результаты не повторяются автоматически. Платный API не подставляется вместо подписки. При недоступном GPT Image обновите официальный Codex, проверьте доступ подписки и повторите диагностику. Не ослабляйте проверки ради зелёного статуса.

Утренние сводки, рекламный ИИ и ежедневные задачи включаются **отдельно** после согласования магазинов, источников и расхода лимита. Инструкции — INSTALL.md и STOMETRIC.md. Один разбор задач включает как минимум четыре запроса. Для WB нужны дневные точки входа за восемь завершённых дней; Ozon использует свои источники. Включение VIP само по себе не запускает разбор.

## Обновление, отключение и приёмка

«Выключить личный ИИ» закрывает подписочный маршрут без перехода на API. Для перевода кабинета на API сначала выключите VIP, назначьте API-тариф и подключите отдельный ключ. Старые результаты сохраняются. Настройку нельзя незаметно передать другому суперадминистратору.

В закрытой копии сохраняйте базу, файлы пользователей и профиль личного ИИ с ограниченным доступом. Никогда не публикуйте `data/personal-ai`, `.env` или файлы авторизации. После переноса на другой сервер предпочтителен новый официальный вход владельца; код не копирует токены. На российский сервер цен подписка не переносится.

Автономные тесты: `tests/test_personal_ai.py`, `tests/test_stometric.py`. Они используют синтетическую базу и имитацию ответов Codex. Живой вход и расход вашей подписки проверяет владелец на своей установке: сайт, Telegram, одна картинка, отказ чужому магазину и отзыв доступа. Одна успешная диагностика не заменяет эти сценарии.
