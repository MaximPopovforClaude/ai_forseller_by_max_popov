# Плагин AI-100metric by Max Popov для Chrome · 0.2.8

Плагин сохраняет оригинальный логотип **AI-100metric by Max Popov**. При настройке домена оставляйте `brand.svg` и подпись автора; см. [правила айдентики](../docs/BRANDING.md).

Плагин скачивает «Точки входа» в открытом кабинете продавца Wildberries и передаёт
отчёты на вашу установку платформы. Для загрузки нужна роль редактора или выше.
Плагин доступен на любом тарифе; ключ нейросети для него не нужен.

Автор проекта — Максим Попов. Подписывайтесь на [его Telegram-канал
«Максим Попов. Система и масштабирование на МП»](https://t.me/maxim_popov_wb).

## Первая установка

1. Разверните свою платформу по [гайду](../docs/INSTALL.md).
2. Из корня проекта запустите `.venv/bin/python scripts/configure_extension.py https://analytics.example.org`,
   заменив пример своим HTTPS-доменом. По умолчанию указан пример адреса, а не работающий сервер.
3. Откройте `chrome://extensions`, включите режим разработчика, нажмите
   «Загрузить распакованное» и выберите папку `extension`, содержащую `manifest.json`.
4. В настройках аккаунта вашего сайта получите код плагина, вставьте в окно
   расширения и нажмите «Подключить».
5. В WB выберите юрлицо, обновите вкладку, откройте «Аналитика → Портрет покупателя →
   Точки входа». Дождитесь загрузки и нажмите «Скачать сейчас» в плагине.

## Обновление

Получите свежие исходники и снова запустите configure_extension.py с доменом вашей
платформы. В Chrome перезагрузите карточку «AI-100metric by Max Popov · WB» и проверьте
версию **0.2.8**. Если устанавливаете ZIP со своего сайта, замените файлы в прежней
папке расширения перед перезагрузкой. Кнопка Chrome «Обновить» сама не скачивает
новые файлы распакованного плагина. Затем обновите вкладки WB.

## Ошибки и правила работы

- **401**: WB отклонил текущую сессию. Плагин ждёт её обновления кабинетом до
  10 секунд и может повторить запрос один раз. Если WB требует войти заново,
  войдите, откройте сам отчёт «Точки входа» и повторите скачивание в плагине.
- **403**: проверьте права сотрудника на аналитику в кабинете WB.
- **429 / 5xx / нет связи**: повторите позже и проверьте доступность самого отчёта WB.
- **Нет действующей сессии**: дождитесь загрузки раздела «Точки входа» именно
  в этой вкладке. Данные входа другой вкладки больше не используются.

Пока идёт скачивание, не закрывайте вкладку и не переключайте юрлицо. Один
запуск загружает до семи дней; автоматический сбор постепенно догружает последние
30 дней. Доступность отчёта и входа определяет WB. Cookie и заголовки авторизации
WB остаются в браузере; на вашу платформу передаются отчёты и диагностика этапов
без значений ключей.

В 0.2.8 исправлены общий кэш сессий разных вкладок и повторное использование
отклонённой сессии. Обработка 401, смена кабинета и путь до загрузки проверены
на искусственных данных; вход и скачивание в вашей реальной сессии требуют проверки.
