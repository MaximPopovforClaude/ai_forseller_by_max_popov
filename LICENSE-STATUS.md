# Лицензия ожидает выбора владельца

Эта копия подготовлена для проверки перед распространением. Владелец ещё не выбрал MIT либо AGPL-3.0; ни одна из них этим документом не предоставляется.

Перед публичным размещением владелец должен добавить согласованный LICENSE. До этого не объявляйте проект open source и не выдавайте третьим лицам права, которые ещё не предоставлены. Лицензии зависимостей остаются их собственными; перечень прямых зависимостей — requirements.txt и web/frontend/package.json, версии фронтенда закреплены bun.lock.
